# 카테고리 - 근거 문서 매핑표

근거 문서: `docs/sme_ai_doctor_service_manual.md`

| 카테고리 | 설명 (어떤 문의인가) | 매핑되는 문서 섹션 | 분류 근거 |
|---|---|---|---|
| 진단 | 5차원 프레임워크, 인터뷰 진행방식·횟수, 진단 산출물에 대한 문의 | `## 진단` (5차원 진단 프레임워크 / 진행 방식 / 산출물) | 서비스의 첫 단계, "우리 회사가 대상이 되는가"를 판단하는 절차 자체에 대한 질문 |
| PoC | PoC 진행 여부·기간·산출물·대표 공유 여부에 대한 문의 | `## PoC` | 기술 검증 단계, 진단 이후 "되는지 안 되는지"를 확인하는 절차 |
| PRD | PRD 7개 항목, 핵심기능 개수 제한, 계약·서명 여부에 대한 문의 | `## PRD` | 범위·성공기준을 확정하는 절차. "계약을 맺나요?"처럼 계약처럼 보이지만 실제로는 구두 합의임을 밝히는 질문 포함 |
| MVP | MVP 완성도 기준, 테스트 데이터, 구현 방식에 대한 문의 | `## MVP` | 실사용 가능 여부를 확인하는 마지막 절차 |
| 범위 밖 | 비용, 계약 기간·조건, 타 산업 법률/세무 자문 등 서비스 절차 밖의 문의 | `## 안내 범위` (매핑되는 실질 내용 없음 — "다루지 않는다"는 사실 자체가 근거) | 문서 어디에도 답이 없음. 지어내지 않고 넘기는 것이 정답 |

## 판정 규칙

- 질문이 진단·PoC·PRD·MVP 중 하나의 절차 내용을 묻고 있으면 해당 카테고리로 분류하고, 매핑된 섹션만 근거로 조회한다.
- 비용·계약조건·일정·타 산업 자문처럼 매뉴얼에 실질 내용이 없는 주제는 **범위 밖**으로 분류하고, 근거를 조회하지 않고(또는 `## 안내 범위`만 조회하고) 넘긴다.
- 두 카테고리에 걸친 질문(예: "PoC 끝나고 PRD는 언제 하나요?")은 질문의 **주된 의도**를 기준으로 하나만 고른다 — 이 케이스는 평가셋에 별도로 포함해 분류기 판단을 확인한다.
